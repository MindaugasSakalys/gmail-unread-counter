Privacy Policy – Gmail Unread Counter

Last updated: September 6, 2026

Gmail Unread Counter is a Chrome extension designed to display the number of unread messages in the user's Gmail Primary inbox on the Chrome toolbar.

Google Account and Gmail Access

The extension uses Google OAuth authentication and the Gmail API to access information necessary to determine the number of unread messages in the user's Primary inbox.

The extension does not use Gmail data for advertising, profiling, creditworthiness, or any purpose unrelated to displaying the unread message count.

Data Collection and Storage

Gmail Unread Counter does not operate its own external server or database for storing Gmail data.

Gmail information retrieved through the Gmail API is processed by the extension only as necessary to calculate and display the unread Primary inbox count.

The extension does not sell user data or transfer user data to third parties except as necessary for the operation of Google services requested by the user.

Personal Communications

The extension accesses Gmail message-list information solely to identify messages matching the user's unread Primary inbox. It does not collect or store email message bodies for external use.

Data Sharing

User data is not sold or used for advertising, marketing, lending, or creditworthiness purposes.

Permissions

The extension uses Google authentication, Gmail API access, and Chrome extension permissions required to periodically update the unread message count.

Changes to this Privacy Policy

This Privacy Policy may be updated if the extension's functionality or data practices change.
